# 안부 기록장 (v1.0.0)

노인맞춤돌봄서비스 생활지원사·전담사회복지사가 방문(또는 안부 전화) 뒤 살핀 내용을 고르면, 두괄식 결과 보고서 본문 문단을 만들어 주는 웹앱입니다.

- 앱 주소: https://86loading-droid.github.io/anbu-note/
- 구성: `index.html` 한 파일(서버 없음, 외부 전송 없음)

## 쓰는 법
1. 방문 정보(날짜·방식·어르신 호칭·다음 방문일)를 적습니다.
2. 「오늘 살핀 것」에서 영역을 열고 세부 영역 → 관찰한 모습 → 어르신 말씀을 고릅니다. 한 영역에 여러 줄을 쓸 수 있습니다.
3. 어르신만의 키워드(예: 손녀 결혼식, 호박죽)를 종류와 함께 넣으면 해당 영역 문장에 들어갑니다.
4. 결과 문단은 첫 문장에 종합 판단(위험 신호 → 살펴볼 점 → 평소 상태 순)을 두고, 근거·제공 서비스·다음 계획이 이어집니다.
5. 「표현 바꾸기」로 문장을 다른 표현으로 돌리고, 「직접 고치기」로 손본 뒤 「문단 복사」합니다.

## 원칙
- 고르지 않은 내용은 문장에 넣지 않습니다. 위험 신호를 골라도 보고·연계 문장은 실제로 한 조치를 고를 때만 들어갑니다.
- 입력과 저장(어르신 호칭·키워드, 작성 중 일지)은 이 브라우저(localStorage) 안에만 남습니다.
- 서비스 구분: 보건복지부 『2026년 노인맞춤돌봄서비스 사업안내』 직접서비스(안전지원·사회참여·생활교육·일상생활지원), 연계·특화서비스.
